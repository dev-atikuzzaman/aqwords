# আল-কুরআন ডিকশনারি

আল-কুরআনের গুরুত্বপূর্ণ **শব্দসমূহ** ও ৮০/২০ নীতি অনুসারে বাছাইকৃত **গুরুত্বপূর্ণ আয়াতসমূহ** নিয়ে একটি ইনস্টলযোগ্য, অফলাইন-সক্ষম PWA (Progressive Web App)। প্রতিটি এন্ট্রিতে রয়েছে ব্যাখ্যা, উপমা/এনালজি, বাস্তব উদাহরণ, বিজ্ঞানের সাথে তুলনা, প্রেক্ষাপট, তাৎপর্য, সম্পর্কিত হাদিস ও রেফারেন্স।

## ⚠️ গুরুত্বপূর্ণ দ্রষ্টব্য (অবশ্যই পড়ুন)

এই অ্যাপটি একটি **শিক্ষামূলক স্টার্টার টেমপ্লেট** হিসেবে তৈরি করা হয়েছে — এতে থাকা কুরআনের আয়াত রেফারেন্স, ভাবার্থ, তাফসীর-ভিত্তিক ব্যাখ্যা ও হাদিস রেফারেন্সগুলো প্রকাশ/বিতরণ করার আগে **অবশ্যই একজন যোগ্য আলেম বা নির্ভরযোগ্য ইসলামী প্রতিষ্ঠানের মাধ্যমে যাচাই** করিয়ে নেওয়া জরুরি। বিশেষভাবে লক্ষ্যণীয়:

- **আয়াতের আরবি টেক্সট (তাশকীল/হরকতসহ)** প্রতিটি আয়াতে যুক্ত করা হয়েছে, একাধিক নির্ভরযোগ্য উৎস (Quran.com/QuranFoundation-এর Uthmani রেন্ডারিং ও একাধিক স্বতন্ত্র তাফসীর ওয়েবসাইট) থেকে ক্রস-চেক করে। তারপরও ছাপার আগে অন্তত একটি প্রিন্টেড/সরকারি অনুমোদিত মুসহাফের সাথে মিলিয়ে নেওয়ার পরামর্শ দেওয়া হচ্ছে — টাইপোগ্রাফিক ভুলের ঝুঁকি সবসময় থেকেই যায়।
- **হাদিস রেফারেন্সগুলো** সাধারণভাবে সুপরিচিত ও ব্যাপকভাবে উদ্ধৃত হাদিসের ভিত্তিতে দেওয়া হয়েছে, তবে প্রতিটি হাদিসের সনদ, বর্ণনাকারী ও নির্ভুল নম্বর হাদিস বিশারদ বা নির্ভরযোগ্য হাদিস ডাটাবেজ (যেমন সুনান.কম, hadithenc.com) থেকে ক্রস-চেক করে নিন।
- **বিজ্ঞানের সাথে তুলনা** অংশগুলো অনুপ্রেরণামূলক ও আলোচনামূলক দৃষ্টিভঙ্গি থেকে লেখা — বৈজ্ঞানিক প্রমাণ হিসেবে নয়, চিন্তার খোরাক হিসেবে উপস্থাপিত। সৃষ্টিতত্ত্ব/বিজ্ঞান বিভাগের কিছু এন্ট্রিতে সতর্কতামূলক মন্তব্যও যোগ করা হয়েছে।
- ডেটাসেট ধাপে ধাপে সম্প্রসারণ করা হচ্ছে — বর্তমানে `data/words.js`-এ ৪৯টি শব্দ ও `data/ayahs.js`-এ ২৫টি আয়াত আছে। একই ফরম্যাট অনুসরণ করে ভবিষ্যতে আরও এন্ট্রি যোগ করা যাবে।

## ✨ ফিচার

- **দুটি প্রধান বিভাগ** — আয়তাকার কার্ডের মাধ্যমে "শব্দসমূহ" ও "গুরুত্বপূর্ণ আয়াতসমূহ" নির্বাচন
- প্রতিটি এন্ট্রিতে: ব্যাখ্যা, উপমা, উদাহরণ, বিজ্ঞানের সাথে তুলনা, প্রেক্ষাপট, তাৎপর্য, সম্পর্কিত হাদিস ও রেফারেন্স
- **সম্পূর্ণ অফলাইন** — কোনো ব্যাকএন্ড সার্ভার নেই, সব ডেটা অ্যাপের ভেতরেই বান্ডেল করা
- **ইনস্টলযোগ্য PWA** — মোবাইল/ডেস্কটপে হোমস্ক্রিনে ইনস্টল করা যায়
- **লোকাল ডেটাবেইজ (IndexedDB)** — ফেভারিট, "শেখা হয়েছে" প্রগ্রেস ও ব্যক্তিগত নোট ডিভাইসেই সংরক্ষিত
- **সার্চ + বিষয়ভিত্তিক ফিল্টার**
- **"আজকের নির্বাচন"** — প্রতিদিন একটি শব্দ ও একটি আয়াত হাইলাইট হয়
- **অগ্রগতি ট্র্যাকার**

## 🛠️ প্রযুক্তি স্ট্যাক

| স্তর | প্রযুক্তি |
|---|---|
| ফ্রেমওয়ার্ক | Next.js 14 (App Router, static export) + React 18 |
| স্টাইলিং | Tailwind CSS 3 |
| লোকাল ডেটাবেইজ | নেটিভ IndexedDB (কোনো এক্সটার্নাল লাইব্রেরি ছাড়াই) |
| PWA / অফলাইন | হাতে লেখা `sw.js` (runtime cache-first) + `manifest.json` |
| ফন্ট | Noto Serif Bengali, Hind Siliguri, Amiri (আরবি), Inter |

কোনো ব্যাকএন্ড সার্ভার বা API নেই — পুরো অ্যাপ একটি স্ট্যাটিক বান্ডল (Next.js `output: 'export'`), যা Vercel/Netlify/GitHub Pages-এ বিনামূল্যে হোস্ট করা যায়।

## 💻 লোকালে চালানো

```bash
npm install
npm run dev
```

`http://localhost:3000` এ ব্রাউজারে খুলুন।

বিল্ড করার জন্য (static export তৈরি হবে `out/` ফোল্ডারে):
```bash
npm run build
```

## 🚀 GitHub-এ পুশ ও Vercel-এ ডিপ্লয়

```bash
cd quran-dictionary

git branch -M main
```

[vercel.com](https://vercel.com)-এ GitHub রিপো import করুন — Next.js ফ্রেমওয়ার্ক স্বয়ংক্রিয়ভাবে সনাক্ত হবে, কোনো কনফিগারেশন পরিবর্তনের প্রয়োজন নেই। **Deploy** ক্লিক করলেই লাইভ লিংক পাওয়া যাবে।

### PWA ইনস্টল করা

লাইভ সাইটে গিয়ে ব্রাউজারের এড্রেস বারে "Install" আইকনে ক্লিক করুন (Chrome/Edge) বা মোবাইলে "Add to Home Screen" ব্যবহার করুন।

## 📝 নতুন শব্দ/আয়াত যুক্ত করা

`data/words.js`-এ নিচের ফরম্যাটে একটি অবজেক্ট যুক্ত করুন:

```js
{
  ar: "আরবি শব্দ",
  translit: "প্রতিবর্ণীকরণ",
  bn: "বাংলা অর্থ",
  root: "মূল ধাতু (যদি প্রযোজ্য)",
  def: "ব্যাখ্যা...",
  analogy: "উপমা/এনালজি...",
  example: "বাস্তব উদাহরণ...",
  science: "বিজ্ঞানের সাথে তুলনা...",
  context: "প্রেক্ষাপট...",
  significance: "তাৎপর্য...",
  hadith: "সম্পর্কিত হাদিস...",
  hadithRef: "হাদিস রেফারেন্স",
  refs: ["সূরা নাম আয়াত নম্বর"],
  category: "faith | worship | character | society | creation | akhirah | heart | guidance",
  tags: ["tag1", "tag2"],
  level: "core | practical | advanced",
}
```

`data/ayahs.js`-এ একই রকম কাঠামো, তবে `ar/translit/bn/root/def` এর বদলে `surah/surahEn/ref/title/meaning/explanation` ফিল্ড ব্যবহার করা হয়েছে — বিদ্যমান এন্ট্রি দেখে অনুসরণ করুন।

`id` ও `letter` স্বয়ংক্রিয়ভাবে `data/index.js`-এ তৈরি হয়, আলাদা করে দেওয়ার প্রয়োজন নেই।

## 📄 লাইসেন্স

এই কোডবেস স্বাধীনভাবে ব্যবহার, পরিবর্তন ও পুনর্বিতরণ করা যাবে। কনটেন্ট (আয়াত ভাবার্থ, হাদিস রেফারেন্স ইত্যাদি) প্রকাশের আগে উপরের দ্রষ্টব্য অনুযায়ী অবশ্যই যাচাই করে নিন।
